AI修正案を比較して、採用版を残す

AIで文章を修正したあと、どの案を採用したか、なぜ選んだかを残すための実例と道具をまとめています。 原文と修正案を比べる例、採用版と判断理由を保存する無料ツール、根拠や段落構成を整える2つの日本語ライティングスキルを使えます。

2つの規範

japanese-tech-writing

主張と根拠、因果と不確実性、段落構成、読み手の負荷を整えます。

cognitive-rhythm-writing

文の拍、密度の波、節の入り方、問いの回収を設計し、読者が論旨をたどれる文章を目指します。

ブラウザーで採用版を記録する

AI修正後の採用版を残す無料ツールでは、原文と修正候補を並べ、現在使う文章と判断理由をMarkdownファイルに保存できます。入力内容はサーバーへ送信しません。

実例

同じ事実でも、順序と段落の役割を変えると、説明の筋道が追いやすくなります。Before/Afterと、効いた規範を確認できます。

  • 技術文書・障害報告・比較記事などの実例一覧
  • AI修正前後を比べ、採用版と根拠を残す実例
  • AI修正後の採用版を記録する雛形
  • AI修正後の採用版の記入例
  • AI修正後に数字の不一致を見つけ、採用を見送る記録例

AI修正案の比較・事実確認・採用版の記録を、確認表と指示文で進めたい場合は、採用版チェックリストと指示文（500円、買い切り）をご覧ください。無料部分で内容を確認できます。
