# AI修正後の採用版を記録する

この雛形は、元の文章とAIの修正候補を比べ、人が採用した版と判断理由を残すための記録欄です。

修正候補をそのまま元の文章へ上書きせず、原文と候補を別々に保存してから使ってください。

```text
対象の文章:
作業日:
修正の目的:

元の文章の保存先または版:
修正候補の保存先または版:

変更した箇所:
変更の理由:

照合した項目:
- 数字:
- 固有名詞:
- 条件:
- その他:

判断: 採用 / 見送り / 保留
採用した版の保存先:
判断の理由:
未確認の点:
```

数字、固有名詞、条件は元資料と照らして確認します。
照合できない項目があれば、空欄を推測で埋めず「未確認」と記録してください。

この雛形は記録欄の例であり、修正内容の正しさを保証するものではありません。
Before/Afterの[記入例](06-ai-revision-adopted-version.md)も公開しています。

より詳しい確認表と指示文を使う場合は、[採用版チェックリストと指示文](https://note.com/smartcareviz/n/naf463e2cc4cb)を参照してください。
