# AI修正後の採用を見送る記録例

次の例は、記録欄の使い方を示すために作った架空の例です。実在の文書やAIの出力を再現したものではありません。

## 元の文章

受付時間は平日17時までです。

## 修正候補

受付時間は平日18時までです。

## 記録欄への記入例

```text
対象の文章: 窓口案内
作業日: 記入例。実際の作業日ではない
修正の目的: 受付時間を短く明確に示す

元の文章の保存先または版: 窓口案内 v1（架空）
修正候補の保存先または版: 窓口案内 修正候補A（架空）

変更した箇所: 受付終了時刻を17時から18時に変更
変更の理由: AIの修正理由に具体的な根拠は示されていない

照合した項目:
- 数字: 17時が18時に変わっている
- 固有名詞: 該当なし
- 条件: 平日の受付という条件は維持

判断: 見送り
採用した版の保存先: なし
判断の理由: 元の文章と異なる終了時刻を裏付ける情報がない
未確認の点: 正しい受付終了時刻。担当部署の案内で確認する
```

文として読みやすくなっても、数字の変更を裏付けられない場合は採用を保留します。元資料で正しい時刻を確認できるまでは、元の文章を現在版として残します。

確認欄と比較・事実確認に使う指示文をまとめた[採用版チェックリストと指示文](https://note.com/smartcareviz/n/naf463e2cc4cb)もあります（500円）。購入前に、無料部分で内容を確認できます。
