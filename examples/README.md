# Before / After実例の読み方

01〜06は、一般的な技術題材を使った架空のBefore / After例です。
08は、採用版の記録欄を埋める架空の例です。07はコピーして使える空欄の雛形です。
09は、元の数字を変えた修正候補を見送り、未確認点を残す架空の例です。
いずれも実在する組織、製品の内部事情、運用記録には基づいていません。

Beforeは、文法的には読めて情報も並んでいる、現実的な初稿として書いています。
わざと壊した文を直して差を大きく見せる例ではありません。

Afterを読むときは、語尾の変化より次の点を比べてください。

- 段落の先頭だけで、その段落の役割がわかるか
- 事実、推定、因果、制約が混ざっていないか
- 列挙した項目が、最後の判断に一つずつ結び付いているか
- 長い説明のあいだに、読者が立ち止まれる短い文があるか
- 冒頭で開いた問いや違和感が、放置されていないか
